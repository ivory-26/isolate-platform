## Provider usage policy (applies to every skill/agent above)

Baseten and Modal are credit-funded. Projects skills must not trigger paid calls. Keys are the last step; all work runs with `INFERENCE_PROVIDER=none` / `SANDBOX_PROVIDER=null`, and live verification is one bounded acceptance pass with explicit user approval. Canonical policy: [`AGENTS.md`](../AGENTS.md) §Provider credits. A skill that suggests benchmarking, retrying, or experimenting against a live provider must be rejected in review.
